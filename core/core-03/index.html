    Provenance and evidence custody¶

    The presentation distinguishes traces of events, attributed reports and authoritative references, and stresses origin, version, applicability and custody. These categories are not interchangeable evidence grades.

    Implementation custody protocol: register original bytes without alteration; calculate SHA-256; record acquisition time, custodian, access scope and rights; create separately identified extraction/translation derivatives; link each claim to a source version and precise locator; retain contradictions and superseded revisions. A hash supports integrity comparison, not authorship or truth.

    An operational custody ledger must record actor, timestamp, input/output hashes, action, reason and authorization. This local package fingerprints the supplied PDF but does not distribute it, retain its personal watermark or implement a tamper-proof custody service.
